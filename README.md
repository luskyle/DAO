# DAO · 道

> 我一直在尝试去理解解释这个世界。用了很多方式与理论，代入真实世界之后，每种理论都不完整，都有出入。直到有一天，我顿悟了。我找到了一种合理的方式。那就是道。
> 其实道的理论，是我最先尝试的，但当时理解得过于片面，总觉得离现代真实生活太远，也不能解释过去的历史，充斥着大量唯心的观点，所以我不能认同。其实我是很反对唯心论的理论的，我自认为是个坚定的唯物主义者。但是如果说有哪种论述能够解释这个世界的一切，我想不出比道更加合适的。所以，我会用道来阐述我的理论。一家之言。

道可道，非常道。我可以跟你们说道是什么，但绝不是你们理解的道法，也不是某种道理，或者是某个路线。我的所有依据都是基于事实，不会凭空捏造，不凭主观臆断，对所有主管臆断的理论，以及脱离时空背景的理论，我都拒绝。自然，我会怀抱着理解的心态，尽可能阐明时代以及人的个体认知的局限性，或者差异性。

这个世界存在道，你可以理解为某些底层的或者表层的逻辑，你也可以把它理解成某些规则约束。谈到规则，有自然的规则，人为的规则，自然的规则只能遵守与利用，人为的规则你可以遵守利用，也可以无视打破，因为没有人就没有规则，人为的规则本就不存在，人的规则只适用与人，这自然充斥着许多局域性。我把这个世界用道来解释，根据具体领域的不同，将解释的角度划分为5类：天道、人道、神鬼道、科学以及精神力。如果追究根本，这个世界只有天道，天道是长存的。没有天道，就没有人道。而神鬼道、科学是从人道生发而来的，没有人道，它们也不存在。至于精神力，这是个很特别的东西。有生物才有意识，才有精神力。精神力能够引导生物产生行为，本能的或者是后天的。神鬼道，科学都是在精神力的作用下，在人类社会产生的，根植于人类社会，不存在于这个世界的高级抽象。本质上，神鬼道的作用与科学的作用是一样的。他们都在回答这样的问题：

* 这个世界是什么样的？从哪里来？为什么是现在这个样子？未来会是什么样子？

而二者的区别在于：神鬼道解释世界依靠各种传说故事，利用人们对事物的不了解，因为不了解，所以经过一通渲染，或让人向往，或让人恐惧，从而区分出对错，定下严格铁律，约束信众的行为。许多人就是这么可笑，被一个个神秘的故事蒙蔽。而如果不是因为有利可图，也不会产生庞大的信众团体。这是从负面来看神鬼道。如果从正面来看，神鬼道的存在安抚了人类的焦虑，让人们对未来抱有憧憬，心怀希望。虽然这些是建立在非常荒谬可笑的，虚无的基础上的。所以，当哥白尼提出日心说的时候，当科学开始用客观的，可反复验证的证据试图解释这个世界的时候，这毫无疑问动摇了神鬼道的统治根基，触动了那些团体的利益。这让他们感到恐惧。进而利用自己组织庞大的影响力，迫害那些被他们视作异端的人，抑制被他们视作歪理邪说的流行。然而，科学是可以反复检验证明的，而且能够让人有效地解释这个世界。人类使用科学证据来解释天道，用唯物主义来看待这个世界。人类不需要再依靠祈祷，献祭来祈求神鬼的施舍拯救。依靠自己，依靠科学，才有了你我看到的当今世界。这是科学中几百年间带给人类世界翻天覆地的变化。

但神鬼道并未消亡，因为它很好用。例如，神鬼道与科学结合诞生了许多现代神秘故事。最典型的就是外星人。这完全不值得辩驳，毫无意义。类似于外星人的故事，其本质就是利用人类对未知的向往、恐惧、好奇、甚至贪婪。这丰富了我们的生活，但你要是真相信这些神神鬼鬼的东西，那我也无话可说。毕竟这是你自己的事，你可以选择相信，也可以去传播，也可以固执地坚信，但请不要极端，更不要对他人施以极端。很可笑，相信神鬼道的人从古到今，一向都是极端的。不止神鬼的事，人类可以因为所有事情走上极端。这里我就不一一展开了。

我会花很长的时间与篇幅，来尝试解释天道、人道、神鬼道、科学、精神力。天道部分探究的是世界的本质，这与人或者任何别的生物无关，当然，生物也是天道的一部分，但是它太特殊了，所以我不打算在天道部分论述生物。毕竟生物的天理，终究是不如生物性更有趣。人道部分探究的是人类这个物种的方方面面。自然，物种不同，猫猫狗狗，就算是一只蚂蚁，一个细菌也都有自己的道，都有其在这个世界存在的原因，有其在这个世界存在的方式，所以人类不要太过自大了。我们不是这个世界的唯一，也并不掌控这个世界，这个世界不围绕人类转，这个世界的生物也没有义务，人类更没有这个权利要求它们围绕人类转。天道之下，众生都是平等的。神鬼道部分我会从人类社会最原始时期开始，讲述它们的起源，发展，但根本目的在于阐述人类当年的认知局限性，以及其本来可能的真相。科学与神鬼道都有试图解释天道的部分，我会在讲述科学的时候，尽量避免它的故事性，只讲科学本身。我认为这是科学区别于神鬼故事的严肃纪律。精神力部分，我会将人类或者别的生物的情感剥离开，探讨人性，生物性。

这5个方面完全写完，将是划时代的鸿篇巨著，希望未来我可以坚持下去。
