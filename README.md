# DAO · 道

以“道”为线索，探索天地、人间、神鬼、科学与精神体验。项目尝试用开放、清晰的文章，记录人们理解世界与自身的不同路径；对事实、信仰、推测和个人体验分别对待，不把它们混为一谈。

网站使用 Jekyll 构建并部署在 GitHub Pages。

## 主题

- [天道](./天道/)：天地、自然与万物运行的规律
- [人道](./人道/)：人的生命、关系、社会与处世
- [神鬼道](./神鬼道/)：神话、宗教、民俗与未知叙事
- [科学](./科学/)：以观察、证据与实验检验认识
- [精神力](./精神力/)：意识、专注、体验与内在生活

目前仓库中各主题目录已建立，文章内容仍在整理中。新增文章时使用 Jekyll 页面 front matter，并将文件放入相应主题目录。
