# DAO · 道

> 我一直在尝试去理解解释这个世界。用了很多方式与理论，代入真实世界之后，每种理论都不完整，都有出入。直到有一天，我顿悟了。我找到了一种合理的方式。那就是道。
> 其实道的理论，是我最先尝试的，但当时理解得过于片面，总觉得离现代真实生活太远，也不能解释过去的历史，充斥着大量唯心的观点，所以我不能认同。其实我是很反对唯心论的理论的，我自认为是个坚定的唯物主义者。但是如果说有哪种论述能够解释这个世界的一切，我想不出比道更加合适的。所以，我会用道来阐述我的理论。一家之言。

道可道，非常道。我可以跟你们说道是什么，但绝不是你们理解的道法，也不是某种道理，或者是某个路线。我的所有依据都是基于事实，不会凭空捏造，不凭主观臆断，对所有主管臆断的理论，以及脱离时空背景的理论，我都拒绝。自然，我会怀抱着理解的心态，尽可能阐明时代以及人的个体认知的局限性，或者差异性。

这个世界存在道，你可以理解为某些底层的或者表层的逻辑，你也可以把它理解成某些规则约束。谈到规则，有自然的规则，人为的规则，自然的规则只能遵守与利用，人为的规则你可以遵守利用，也可以无视打破，因为没有人就没有规则，人为的规则本就不存在，人的规则只适用与人，这自然充斥着许多局域性。我把这个世界用道来解释，根据具体领域的不同，将解释的角度划分为5类：天道、人道、神鬼道、科学以及精神力。如果追究根本，这个世界只有天道，天道是长存的。没有天道，就没有人道。而神鬼道、科学是从人道生发而来的，没有人道，它们也不存在。至于精神力，这是个很特别的东西。有生物才有意识，才有精神力。精神力能够引导生物产生行为，本能的或者是后天的。神鬼道，科学都是在精神力的作用下，在人类社会产生的，根植于人类社会，不存在于这个世界的高级抽象。


































以“道”为线索，探索天地、人间、神鬼、科学与精神体验。项目尝试用开放、清晰的文章，记录人们理解世界与自身的不同路径；对事实、信仰、推测和个人体验分别对待，不把它们混为一谈。
